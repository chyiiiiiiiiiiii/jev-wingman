# 〈我的截圖朋友失業了〉拍攝清單

全片 52.5 秒，只有 6 個鏡頭要拍，其他都是 app 畫出來的畫面。先看 `out/reel-01.mp4`：灰色虛線框就是這 6 個鏡頭的位置和長度。

## 拍之前

- 手機直拿（9:16），30 或 60 fps，4K 或 1080p 都可以。
- 手機要固定，靠書堆或腳架都行。長按畫面鎖定對焦和曝光，畫面才不會一直變亮變暗。
- 側面約 45 度，入鏡範圍是臉、手和螢幕邊緣。
- 螢幕上不要出現真的聊天。有兩種做法：
  - 最真實：請朋友在 Slack 或 LINE 傳一句「明天早上的簡報，你那邊 OK 嗎？」給你，你真的按 ⌥Space 操作 Wingman。
  - 最省事：螢幕失焦（對焦在臉上），開著任何不含私人內容的畫面。
- 每個鏡頭多錄幾秒（4–6 秒），錄 2–3 次，我會挑最好的那段。

## 6 個鏡頭

| 鏡頭 | 片中長度 | 場景 | 你要做的事 |
|---|---|---|---|
| A | 2.2 秒 | 深夜，只開桌燈 | 盯著螢幕，嘆一口氣、抓頭（開場鏡頭，表情可以誇張一點） |
| B | 2.0 秒 | 手部特寫，鍵盤 | 打幾個字，再按 Delete 刪掉 |
| C | 1.4 秒 | 手部特寫，鍵盤 | 按 option + space，按得清楚、有一點儀式感 |
| D | 2.0 秒 | 側拍 | 盯著螢幕打字，把空格改成「12 點」 |
| E | 1.8 秒 | 側拍 | 點個頭，自己按 Enter 送出 |
| F | 1.6 秒 | 隔天早上，窗邊自然光（可以換件衣服） | 看到手機或螢幕，一臉心虛偷笑 |

## 拍完

把檔案命名為 `A.mov` 到 `F.mov`（.mp4 也可以），放進 `promo/reel-01/footage/`，然後執行：

```bash
scripts/make-reel.py reel-01
```

如果最好的那段不是從第 0 秒開始，在 `footage/cuts.json` 寫上起點，例如 `{"A": 1.5}`，或直接跟我說。

## 發布

- 音樂在 IG 裡加熱門音樂，音量約 20–30%。片子裡已經有訊息聲、打字聲和 Wingman 填入的音效。
- 封面用第一格「我最好的朋友，昨天失業了。」
- 片中所有對話都是虛構的。面板上的判斷和草稿，都是 Wingman 對這些對話真的跑出來的結果（`staged.json`）。
